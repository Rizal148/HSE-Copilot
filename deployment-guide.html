🐳 Docker Containerization

Docker allows you to package your entire application (Frontend + Backend + Database) into a container that can run anywhere.

What is Docker?

Docker creates a "container" with everything your app needs to run. It's like shipping your app in a box that works on any computer.

Step 1: Create Backend Dockerfile

Create a file named Dockerfile in the backend/ folder:

FROM node:16
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 5000
CMD ["npm", "run", "dev"]

Step 2: Create Frontend Dockerfile

Create a file named Dockerfile in the frontend/ folder:

FROM node:16 as build
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM node:16
WORKDIR /app
RUN npm i -g serve
COPY --from=build /app/build ./build
EXPOSE 3000
CMD ["serve", "-s", "build", "-l", "3000"]

Step 3: Create docker-compose.yml

Create this file in your project root directory:

version: '3.8'
services:
  db:
    image: postgres:13
    environment:
      POSTGRES_PASSWORD: password
      POSTGRES_DB: hse_copilot
    volumes:
      - postgres_data:/var/lib/postgresql/data

  backend:
    build: ./backend
    ports:
      - "5000:5000"
    depends_on:
      - db
    environment:
      DATABASE_URL: postgresql://postgres:password@db:5432/hse_copilot

  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    depends_on:
      - backend

volumes:
  postgres_data:

Step 4: Run with Docker

docker-compose up

That's it! Your entire app runs with one command.

⚡ Quick Start: Deploy to Render

Why Render?

  • Complete solution (Frontend + Backend + Database)
  • Absolutely free ($0/month)
  • Takes only 5 minutes to setup
  • Auto-deploys when you push to GitHub
  • Production-ready

Prerequisites

  • ✓ GitHub account (free)
  • ✓ HSE-Copilot code pushed to GitHub
  • ✓ Render account (free signup)

Step 1: Sign Up on Render

1. Visit render.com

Go to https://render.com and click "Sign Up"

2. Connect GitHub

Click "Sign up with GitHub" and authorize Render to access your repositories

Step 2: Deploy Backend

Create Web Service

Steps:

  1. Click "New +" button
  2. Select "Web Service"
  3. Connect your HSE-Copilot GitHub repository
  4. Choose "Node" as runtime
  5. Set these values:
    Name: hse-copilot-backend
    Root Directory: backend
    Build Command: npm install
    Start Command: npm run dev
  6. Add Environment Variables (click "Add Environment Variable"):
    DATABASE_URL: postgresql://postgres:password@localhost:5432/hse_copilot
    JWT_SECRET: your_secret_key_here
    NODE_ENV: production
    API_URL: https://your-app.onrender.com
    CLIENT_URL: https://your-app-frontend.onrender.com
  7. Click "Create Web Service"

Step 3: Deploy Frontend

Create Another Web Service for Frontend

Steps:

  1. Click "New +" again
  2. Select "Static Site" (or Web Service)
  3. Connect same GitHub repository
  4. Set these values:
    Name: hse-copilot-frontend
    Root Directory: frontend
    Build Command: npm install && npm run build
    Publish Directory: build
  5. Add environment variable:
    REACT_APP_API_URL: https://your-backend-url.onrender.com
  6. Click "Create Static Site"

Step 4: Setup Database (PostgreSQL)

Option A: Use Render's PostgreSQL

Steps:

  1. In Render dashboard, click "New +"
  2. Select "PostgreSQL"
  3. Fill in details:
    Name: hse-copilot-db
    Database: hse_copilot
    User: postgres
    Region: (closest to you)
  4. Click "Create Database"
  5. Copy the Internal Database URL
  6. Update backend's DATABASE_URL with this URL

Option B: Use External Database

If you have an existing PostgreSQL database, just update the DATABASE_URL environment variable in your backend service.

Step 5: Verify Deployment

Check Status

In Render dashboard, both services should show "Live" status

Access your app:

Frontend: https://your-app-frontend.onrender.com

Backend: https://your-app-backend.onrender.com/api/health

Step 6: Continuous Deployment

Auto-Deploy on GitHub Push

Render automatically deploys your app whenever you push to GitHub!

# Just push your changes to GitHub git add . git commit -m "New feature" git push origin main # Render automatically deploys! ✨

✅ You're Done!

🎉 Your app is live!

Share your app URL with your team. Visit your live URL to see your HSE-Copilot app in action.

Troubleshooting

⚠ Build Failed?

Click the service → "Logs" tab to see detailed error messages

Common issues:

  • ✓ Missing environment variables → Add them in Environment section
  • ✓ Database connection error → Check DATABASE_URL
  • ✓ Node modules error → Clear cache and redeploy
